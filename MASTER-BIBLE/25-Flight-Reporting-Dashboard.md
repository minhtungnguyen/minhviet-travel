# Mục tiêu

Thiết kế hệ thống Dashboard và Reporting giúp Ban lãnh đạo, bộ phận Booking và Kế toán theo dõi hoạt động kinh doanh theo thời gian thực, hỗ trợ ra quyết định nhanh và chính xác.

---

# Đối tượng sử dụng

- Ban Giám đốc
- Admin
- Booking Manager
- Sales Manager
- Kế toán

---

# Dashboard Tổng quan

Hiển thị:

- Booking hôm nay
- Doanh thu hôm nay
- Booking chờ xử lý
- Booking đã xuất vé
- Tỷ lệ thanh toán thành công
- API Provider Status

---

# Dashboard Booking

Theo dõi:

- Booking theo ngày
- Booking theo nhân viên
- Booking theo hãng bay
- Booking theo trạng thái
- Booking sắp khởi hành

---

# Dashboard Kinh doanh

Chỉ số:

- Doanh thu
- Lợi nhuận gộp
- Giá trị booking trung bình
- Tỷ lệ chuyển đổi
- Top tuyến bay
- Top khách hàng

---

# Dashboard Vận hành

- Thời gian xử lý booking
- Queue trạng thái
- API Response Time
- Error Rate
- Notification Success Rate

# Claude Code Guidance

- Dashboard dùng widget tái sử dụng.
- Hỗ trợ filter động.
- Truy vấn tối ưu bằng aggregate.
- Chuẩn bị sẵn API cho BI trong tương lai.
