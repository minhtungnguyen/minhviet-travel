# 13.3 – COLOR & ACCENT SYSTEM

## Mục tiêu

Thiết lập hệ thống màu sắc thống nhất cho toàn bộ hệ sinh thái Minh Việt Travel.

Brand Color luôn là nền tảng.
Emotion Accent tạo cảm xúc theo từng module.

# Quy tắc sử dụng

Emotion Accent chỉ được áp dụng cho:

✓ CTA
✓ Badge
✓ Hover
✓ Divider
✓ Hero Overlay
✓ Icon Highlight

Không sử dụng cho:

✗ Body Text
✗ Background toàn trang
✗ Logo
✗ Header
