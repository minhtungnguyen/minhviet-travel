# EXECUTIVE FINAL APPROVAL CHECKLIST

## Strategy

- [ ] Solves a defined problem
- [ ] Supports Vision 2035
- [ ] Worth doing now
- [ ] Does not distract from higher priorities

## Customer

- [ ] Target persona is clear
- [ ] Customer problem is evidenced
- [ ] Value is measurable
- [ ] Customer journey is improved

## Brand

- [ ] Reinforces Brand Promise
- [ ] Fits The Guide + The Sage
- [ ] Increases trust
- [ ] Avoids misleading or cheap-sales language

## Operations

- [ ] Single accountable Owner
- [ ] Process and exceptions documented
- [ ] Resources available
- [ ] Quality standards defined

## Data and technology

- [ ] Source of truth defined
- [ ] Access control defined
- [ ] Privacy reviewed
- [ ] Logging, backup and recovery addressed
- [ ] Scalable architecture

## Economics

- [ ] Revenue, savings or strategic asset identified
- [ ] Costs understood
- [ ] KPI and payback logic available

## Risk

- [ ] Worst credible outcome assessed
- [ ] Human escalation defined
- [ ] Reversibility and exit plan understood

## Measurement

- [ ] Baseline
- [ ] Target
- [ ] Data source
- [ ] Review date
- [ ] Stop criteria

## Final decision

- [ ] Approve
- [ ] Pilot
- [ ] Revise
- [ ] Reject/Park
