# Claude Code Startup Prompt

Bạn đang làm việc trên Minh Việt Travel Platform.

Thực hiện đúng thứ tự:

1. Đọc `CLAUDE.md`.
2. Đọc toàn bộ thư mục `docs/` theo số thứ tự.
3. Kiểm tra repository hiện tại.
4. Không code ngay.
5. Tạo báo cáo `IMPLEMENTATION_GAP_ANALYSIS.md` gồm:
   - Stack hiện tại.
   - Cấu trúc repository.
   - Module đã có.
   - Module đang lỗi.
   - Schema hiện có.
   - Khoảng cách so với Volume 00.
   - Rủi ro dữ liệu.
   - Rủi ro bảo mật.
   - Kế hoạch Sprint 0.
6. Kế hoạch Sprint 0 phải chia thành task nhỏ, mỗi task có:
   - Mục tiêu.
   - File thay đổi.
   - Migration.
   - Acceptance criteria.
   - Lệnh kiểm thử.
7. Không mở rộng sang app mobile, marketplace hoặc microservice.
8. Dừng lại sau khi tạo báo cáo và chờ phê duyệt trước khi sửa code sản xuất.
