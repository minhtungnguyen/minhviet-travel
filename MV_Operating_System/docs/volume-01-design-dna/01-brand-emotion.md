# 01 — BRAND EMOTION

## 1. Purpose

This chapter defines how people should feel when using Minh Việt Travel Platform.

Design decisions are successful only when they create the intended emotional response while preserving usability and business effectiveness.

---

## 2. Primary Emotional Promise

The platform must make the user feel:

> “My trip or company programme is being handled by a capable, modern and trustworthy travel organisation.”

The user should not feel that they are browsing a noisy promotional catalogue.

---

## 3. Core Emotional Attributes

### 3.1 Trust

Trust is the highest-priority emotion.

Trust is created through:

- complete and legible information;
- visible company identity and contact paths;
- precise itinerary and service descriptions;
- clear booking, payment, cancellation and support policies;
- consistent prices and status labels;
- real operational evidence;
- restrained design;
- predictable interactions.

Trust is damaged by:

- exaggerated claims;
- countdown timers without a real operational basis;
- fake urgency;
- inconsistent prices;
- missing policies;
- excessive decorative badges;
- low-quality stock imagery;
- unclear ownership of the service.

### 3.2 Calm confidence

The interface must feel composed and in control.

Use:

- orderly layout;
- measured typography;
- clear grouping;
- limited simultaneous choices;
- gentle transitions;
- adequate whitespace.

Avoid:

- visual shouting;
- flashing promotions;
- multiple sticky banners;
- aggressive pop-ups;
- animation without functional value.

### 3.3 Premium competence

Premium does not mean exclusive or inaccessible. It means carefully considered and professionally executed.

Premium competence is expressed through:

- strong photography;
- thoughtful editorial layout;
- consistent details;
- complete service content;
- high-quality support cues;
- elegant but restrained brand accents.

### 3.4 Human warmth

The platform must not feel cold or corporate-only.

Human warmth should come from:

- authentic travel moments;
- helpful language;
- knowledgeable advisors;
- local understanding;
- clear support availability;
- stories from destinations, customers and operations.

Warmth must not be created through childish illustration, excessive emojis or informal sales language.

### 3.5 Modern technology

The user should recognise that technology is supporting the experience.

Technology should be visible through:

- fast and relevant search;
- intelligent filtering;
- useful recommendations;
- clear booking progress;
- contextual AI assistance;
- responsive interactions;
- accurate status updates.

Technology should not be expressed through neon gradients, robots, circuit graphics or futuristic decoration.

## 4. Emotional Priority by Product Area

| Product area | Primary emotion | Secondary emotion |
|---|---|---|
| Homepage | Confidence | Inspiration |
| Tour catalogue | Clarity | Discovery |
| Tour detail | Trust | Desire |
| Booking flow | Control | Reassurance |
| Payment step | Security | Simplicity |
| AI planner | Guidance | Curiosity |
| Corporate/MICE | Capability | Professionalism |
| CRM/CMS | Control | Efficiency |
| Customer support | Reassurance | Human warmth |

A page may support several emotions, but it must have one dominant emotional objective.

---

## 5. Brand Personality

Minh Việt Travel Platform behaves like:

- an experienced travel operator;
- a precise programme planner;
- a calm personal advisor;
- a capable corporate partner;
- a modern product company.

It does not behave like:

- a street promoter;
- a coupon marketplace;
- a luxury brand using empty prestige language;
- a chatbot demonstrating technology for its own sake;
- a generic OTA clone.

---

## 6. Tone Translated into Interface Decisions

| Desired emotion | Interface implication |
|---|---|
| Trust | Strong hierarchy, complete facts, visible policies, restrained color |
| Calm | Fewer competing elements, more whitespace, controlled motion |
| Premium | High-quality imagery, editorial composition, precise alignment |
| Warmth | Human content, helpful microcopy, accessible support |
| Technology | Fast workflows, contextual intelligence, clear feedback |
| Professionalism | Consistent terminology, complete states, no visual shortcuts |

---

## 7. Emotional Anti-patterns

The following emotional outcomes are unacceptable:

### Cheap

Caused by:

- excessive yellow;
- discount banners;
- crossed-out prices everywhere;
- crowded badges;
- low-quality destination images;
- promotional copy in all caps.

### Chaotic

Caused by:

- too many content blocks;
- inconsistent spacing;
- many unrelated colors;
- multiple primary buttons;
- uncontrolled animation.

### Outdated

Caused by:

- gradient navigation bars;
- bevel effects;
- glossy buttons;
- thick borders;
- generic travel icons;
- text over busy images without composition.

### Artificial

Caused by:

- fake testimonials;
- overly polished stock portraits;
- invented customer counts;
- decorative AI language;
- imagery unrelated to the actual service.

### Cold

Caused by:

- abstract SaaS patterns dominating travel content;
- no human support cues;
- no destination storytelling;
- overly technical terminology.

---

## 8. Page-level Emotional Test

Before approval, reviewers must answer:

1. What is the dominant emotion of this page?
2. Is that emotion appropriate for the page purpose?
3. Does any element create cheapness, chaos or distrust?
4. Does the interface look like a real travel operation or a generic template?
5. Is technology helping the user or merely decorating the page?
6. Does the user know what to do next?

If reviewers cannot answer Question 1 clearly, the page lacks a coherent emotional hierarchy.

---

## 9. Claude Code Rules

When generating UI, Claude Code must:

- prioritise trust over visual novelty;
- use composition and typography before brand color;
- limit urgency patterns to verified business conditions;
- preserve human support and operational credibility;
- avoid tourist clichés and generic travel templates;
- identify the dominant emotion of each page before implementation.

Claude Code must include the intended page emotion in its implementation plan.
