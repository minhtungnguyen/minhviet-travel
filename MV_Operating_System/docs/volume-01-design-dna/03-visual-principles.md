# 03 - Visual Principles

# Purpose

Định nghĩa ngôn ngữ thị giác cho toàn bộ hệ sinh thái Minh Việt Travel.

## Core Principles

1. Calm before Excitement.
2. Premium before Promotional.
3. Technology before Tourism.
4. Whitespace is a design element.
5. One primary action per screen.

## Layout Rules

- Mỗi màn hình chỉ có 1 tiêu điểm.
- Không quá 2 CTA nổi bật.
- Không dùng banner chồng banner.
- Không quá 3 màu nổi bật trên một màn hình.

## Cards

- Border 1px rất nhẹ.
- Shadow nhẹ.
- Radius 16–20px.
- Không dùng hiệu ứng nổi quá mạnh.

## Hero

- Nền sáng.
- Typography lớn.
- Ảnh chất lượng cao.
- Không dùng stock photo kiểu "giơ tay giữa bãi biển".

## Forbidden

- Giao diện giống OTA giá rẻ.
- Quá nhiều icon.
- Quá nhiều màu.
- Quá nhiều khối quảng cáo.

## Claude Code Rules

- Ưu tiên khoảng trắng.
- Giảm số lượng màu.
- Ưu tiên hierarchy hơn decoration.

## Acceptance Checklist

- [ ] Hero tối giản
- [ ] Chỉ 1 CTA chính
- [ ] Không cảm giác website công ty du lịch truyền thống
