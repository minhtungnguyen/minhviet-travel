# 05 - Typography DNA

# Purpose
Typography là yếu tố tạo cảm giác cao cấp trước cả màu sắc.

## Principles
- Typography dẫn dắt thị giác.
- Ít kiểu chữ, nhiều phân cấp.
- Không dùng font trang trí.

## Font Family
Primary: Inter
Alternative: Manrope

## Hierarchy

### Display
- Dùng cho Hero.
- Rất ít chữ.
- Đậm, nhiều khoảng thở.

### Heading
- Dùng cho tiêu đề section.

### Body
- 16–18px.
- Dễ đọc.

### Caption
- Chỉ dùng cho metadata.

## Rules
- Không quá 2 font.
- Không viết HOA toàn bộ đoạn dài.
- Line-height rộng.

## Forbidden
- Font nghệ thuật.
- Quá nhiều weight.
- Chữ sát nhau.

## Claude Code Rules
Typography must create confidence before decoration.

## Acceptance
- [ ] Chỉ tối đa 2 font
- [ ] Heading nổi bật
- [ ] Body dễ đọc
