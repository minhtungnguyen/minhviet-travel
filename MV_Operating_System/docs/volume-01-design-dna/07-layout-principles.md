# 07 - Layout Principles

# Purpose
Thiết lập quy tắc bố cục thống nhất cho toàn bộ hệ sinh thái.

## Layout DNA
- 12-column responsive grid.
- Max content width: 1280px.
- Một màn hình chỉ có một mục tiêu chính.
- Hero -> Value -> Social Proof -> CTA.

## Desktop
- Header cố định.
- Sidebar chỉ dùng trong CMS.

## Mobile
- Một cột.
- CTA luôn trong vùng dễ chạm.

## Rules
- Không quá 6 card trên một hàng.
- Không quá 3 cấp lồng nhau.
- Khoảng trắng phải lớn hơn khoảng cách giữa các thành phần nhỏ.

## Forbidden
- Banner chồng banner.
- Section không có tiêu đề.
- CTA xuất hiện liên tiếp.

## Claude Code Rules
Always prefer hierarchy over density.

## Acceptance
- [ ] Layout rõ ràng
- [ ] Dễ quét mắt
- [ ] Responsive tốt
