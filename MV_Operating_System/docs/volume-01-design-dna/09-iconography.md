# 09 - Iconography

# Purpose
Icon giúp người dùng nhận biết nhanh chức năng, không dùng để trang trí.

## Design DNA
- Line icon hiện đại.
- Độ dày nét đồng nhất.
- Kích thước mặc định 20px/24px.
- Bo góc mềm, không hoạt hình.

## Rules
- Mỗi hành động chỉ dùng một biểu tượng nhất quán.
- Không pha trộn nhiều bộ icon.
- Icon luôn đứng trước nhãn khi hỗ trợ điều hướng.

## Recommended
- Lucide Icons
- Heroicons

## Forbidden
- Icon 3D.
- Icon nhiều màu.
- Icon hoạt hình.
- Emoji thay icon.

## Claude Code Rules
Use icons only to improve recognition, never as decoration.

## Acceptance
- [ ] Một bộ icon duy nhất
- [ ] Kích thước nhất quán
- [ ] Không gây nhiễu thị giác
