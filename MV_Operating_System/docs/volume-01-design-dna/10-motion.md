# 10 - Motion

# Purpose
Animation phải tạo cảm giác mượt và chuyên nghiệp, không gây phân tán.

## Motion DNA
- Nhanh.
- Tinh tế.
- Có mục đích.

## Duration
- Hover: 150–200ms
- Dialog: 200–250ms
- Page transition: 250–300ms

## Rules
- Fade + Slide nhẹ.
- Skeleton khi tải dữ liệu.
- Không animate mọi thành phần.

## Forbidden
- Bounce.
- Flash.
- Zoom quá mạnh.
- Hiệu ứng liên tục.

## Claude Code Rules
Motion should communicate state changes, not attract attention.

## Acceptance
- [ ] Chuyển động mượt
- [ ] Không gây khó chịu
- [ ] Phản hồi nhanh
