# 14 - Travel Experience

# Purpose
Tạo trải nghiệm truyền cảm hứng nhưng vẫn hiện đại cho khách du lịch.

## Design Goals
- Khơi gợi khám phá.
- Giảm số bước đặt dịch vụ.
- Tăng niềm tin.

## UX Principles
- Tìm kiếm nổi bật.
- Lịch trình dễ đọc.
- Giá minh bạch.
- Đánh giá và hình ảnh thật.

## Visual Style
- Nền sáng.
- Ảnh lớn chất lượng cao.
- CTA rõ ràng.

## Claude Code Rules
Thiết kế phải giống một nền tảng công nghệ du lịch cao cấp, không phải website bán tour truyền thống.

## Acceptance
- [ ] Truyền cảm hứng
- [ ] Dễ đặt dịch vụ
- [ ] Hiệu suất cao
