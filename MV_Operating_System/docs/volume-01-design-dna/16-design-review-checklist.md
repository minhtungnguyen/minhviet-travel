# 16 - Design Review Checklist

# Purpose
Checklist bắt buộc trước khi merge bất kỳ giao diện nào.

## Visual
- [ ] Đúng Brand DNA
- [ ] Đúng Color Philosophy
- [ ] Typography đúng chuẩn
- [ ] Khoảng trắng hợp lý

## UX
- [ ] CTA rõ ràng
- [ ] Điều hướng dễ hiểu
- [ ] Responsive
- [ ] Loading/Error/Empty state đầy đủ

## Technical
- [ ] Component tái sử dụng
- [ ] Không hard-code style
- [ ] Accessibility đạt yêu cầu

## AI
- [ ] AI minh bạch
- [ ] Có trạng thái xử lý
- [ ] Có khả năng chỉnh sửa kết quả

## Claude Code Rules
Không được đánh dấu hoàn thành nếu còn bất kỳ mục nào chưa đạt.

## Acceptance
- [ ] Passed Design Review
