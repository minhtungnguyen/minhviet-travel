# BATCH 01 — ACCEPTANCE CHECKLIST

Use this checklist to review any existing or proposed screen.

## A. Positioning

- [ ] The screen feels like a modern travel platform, not a traditional travel agency.
- [ ] The screen communicates trust before promotion.
- [ ] The interface can credibly serve premium individual and enterprise customers.
- [ ] Technology supports the task without dominating the experience.

## B. Brand Emotion

- [ ] The intended dominant emotion is explicitly identified.
- [ ] The screen feels calm and controlled.
- [ ] The screen avoids cheapness, chaos and artificial urgency.
- [ ] Human support or service credibility is visible where relevant.

## C. Visual Direction

- [ ] Yellow or gold does not dominate the page surface.
- [ ] The hero is not a full yellow promotional banner.
- [ ] Typography and spacing establish hierarchy before color.
- [ ] Photography is credible and relevant.
- [ ] Decorative effects are limited and purposeful.

## D. Information Hierarchy

- [ ] The page has one clear purpose.
- [ ] The page has one primary action.
- [ ] Secondary actions are visually subordinate.
- [ ] Content is progressively disclosed rather than shown all at once.
- [ ] Promotional elements do not overpower essential information.

## E. Authenticity

- [ ] Claims are verifiable.
- [ ] Pricing and availability language is accurate.
- [ ] Reviews, cases and metrics are real or clearly marked as placeholders.
- [ ] AI-generated content is not presented as verified fact without validation.

## F. Responsive and Accessibility

- [ ] Mobile content order is intentional.
- [ ] Text remains readable without compression.
- [ ] Focus, error, loading and empty states are considered.
- [ ] Color contrast and semantic structure are acceptable.
- [ ] Motion can be reduced and does not block use.

## Rejection Triggers

Reject the screen immediately if any item below is present:

- [ ] Main background or hero is dominated by yellow/gold.
- [ ] Multiple primary CTA colors compete.
- [ ] Heavy shadows, thick gold borders or excessive gradients define the design.
- [ ] Generic stock travel imagery creates a dated agency feeling.
- [ ] Fake urgency, fake reviews or unsupported claims are used.
- [ ] Mobile is only a compressed desktop version.

## Result

- **PASS:** No rejection trigger and all critical items satisfied.
- **CONDITIONAL PASS:** No rejection trigger, but minor documented corrections remain.
- **FAIL:** Any rejection trigger or major violation of page purpose, trust or hierarchy.
