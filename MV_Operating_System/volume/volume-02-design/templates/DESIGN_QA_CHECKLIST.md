# Design QA Checklist

## Brand
- [ ] Aligns with Volume 01
- [ ] Tone is trustworthy and professional
- [ ] No misleading urgency, pricing or proof

## UX
- [ ] Primary user job is clear
- [ ] Primary CTA is clear
- [ ] Navigation follows user goals
- [ ] Forms request only necessary data

## States
- [ ] Loading
- [ ] Empty
- [ ] Error
- [ ] Success
- [ ] Disabled
- [ ] Permission denied
- [ ] Long content
- [ ] Missing image/data

## Responsive
- [ ] 360
- [ ] 390
- [ ] 768
- [ ] 1024
- [ ] 1280
- [ ] 1440

## Accessibility
- [ ] Keyboard flow
- [ ] Visible focus
- [ ] Labels
- [ ] Contrast
- [ ] Alt text
- [ ] Reduced motion
- [ ] No color-only meaning

## Technical
- [ ] Real data tested
- [ ] Semantic tokens
- [ ] Reusable components
- [ ] Analytics events
- [ ] Error monitoring
- [ ] Sensitive data protected
- [ ] Performance reviewed
